# Portail de démonstration pour comprendre les recharges en toute sécurité

Site d'une page réalisé avec React et Vite. Le formulaire accepte uniquement une référence fictive au format `DEMO-XXXX-XXXX`. Il ne collecte ni ne transmet de code, PIN, identifiant ou donnée personnelle, et ne vérifie pas les tickets.

## Démarrer
```powershell
npm install
npm run dev
```

Pour créer le site de production : `npm run build`. Vercel utilise la commande `npm run build` et le dossier `dist`.

Les noms PCS, Transcash et Neosurf ne sont pas utilisés comme signe d'affiliation. Pour vérifier un ticket réel, consultez directement le site de son émetteur.
